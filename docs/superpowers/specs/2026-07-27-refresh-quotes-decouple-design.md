# 看板轻量刷新与全量采集解耦设计

## 目标

全量东方财富采集进行中时，看板「刷新 / 自动刷新」仍可立刻更新题材涨跌幅与热度，不再因 409 被锁死。

## 决策

- 产品：全量不挡轻量（用户确认选项 1）
- 方案：解耦锁；轻量 `refresh-quotes` 与全量 `eastmoney` 运行状态独立

## 行为

### 后端

1. `POST /api/v1/scraper/refresh-quotes` **不再**检查 `scraper_scheduler.is_running("eastmoney")`。
2. 仅用进程内 `quotes_refresh_lock`（非阻塞或短等待）防止多个轻量刷新重入；拿不到锁时返回 409「行情刷新进行中，请稍后再试」。
3. 服务启动时清理库内全部僵尸 `running` 采集记录（已有）。
4. 全量采集仍独占 `is_running("eastmoney")`，避免重复全量。

### 前端

1. 自动刷新遇 409（轻量自身重入）静默跳过（已有）。
2. 手动刷新若遇「行情刷新进行中」给出明确 toast，不再提「全量采集」。

## 非目标

- 不改造全量采集耗时与分页策略
- 不做全量/轻量 API 请求队列调度
- 不改变全量触发入口与周期配置

## 风险

全量与轻量可能同时请求东财列表接口，存在限流可能；轻量请求量小、频率受 10/min 限制，可接受。
