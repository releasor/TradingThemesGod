# AI 题材图谱实时更新设计

## 目标

为所有题材提供可配置的模型服务和真实资料驱动的图谱更新。用户在应用内配置模型供应商，题材刷新时抓取公开资料、抽取细分层级并增量写入数据库。无来源、无法验证或抓取失败的数据不得进入正式图谱。

## 模型配置

- 支持 OpenAI-compatible、Anthropic、Gemini、Ollama 四类协议。
- OpenAI-compatible 覆盖 OpenAI、DeepSeek、OpenRouter、硅基流动、各类中转站、LM Studio、vLLM 和 CC-Switch。
- 配置包含名称、协议、API 地址、API Key、模型、自定义请求头、超时、温度和最大输出长度。
- API Key 与自定义请求头在后端加密保存，查询接口只返回脱敏状态，不返回密文或明文。
- 本地实例预置 `http://127.0.0.1:15721/v1` 和 `gpt-5.6-sol`，不预置凭据。
- 设置页支持新增、编辑、删除、启用、设为默认、读取模型列表和测试连接。

## 图谱更新流程

1. 读取题材名称、描述、标签和本地成分股。
2. 通过公开搜索结果获取候选 URL，并抓取可访问网页的标题和正文。
3. 将正文、来源 URL 和允许关联的股票代码传给默认模型。
4. 要求模型返回严格 JSON，包括递归节点、产业链位置、逻辑、催化、风险、可信度、来源引用和股票关联理由。
5. 校验节点必须引用本次抓取来源；股票代码必须存在于本地股票库且属于当前题材成分股。
6. 以稳定路径增量更新节点和股票关系，不删除未出现在本次结果中的旧数据。
7. 空结果或失败不覆盖旧图谱，并向前端返回中文错误。

## 接口与交互

- `/api/v1/model-providers` 管理模型配置。
- `/api/v1/model-providers/{id}/test` 测试连接。
- `/api/v1/model-providers/{id}/models` 获取模型列表。
- `/api/v1/themes/{id}/concept-graph/refresh` 刷新单个题材。
- `/api/v1/themes/concept-graphs/refresh` 批量更新题材。
- 题材详情页“刷新图谱”显示来源数、新增和更新节点数、股票关联数。
- 题材库提供“批量更新图谱”，按当前筛选结果执行有限数量的题材。
- 未配置可用模型时，引导进入设置页，不生成规则猜测数据。

## 安全与失败策略

- 加密主密钥由环境变量或本地密钥文件提供，不进入数据库和前端。
- 日志不得输出 API Key、自定义鉴权头、完整模型请求或网页敏感参数。
- 外部 URL 仅允许 HTTP/HTTPS，并阻止访问回环、私网和链路本地地址，防止 SSRF。
- 请求设置超时、正文长度和来源数量上限。
- 单个来源失败不终止整个抓取；所有来源失败或模型失败时保留原图谱。

## 测试

- 后端覆盖加密脱敏、协议请求构造、JSON 提取、来源和股票验证、增量合并、API 错误。
- 前端覆盖配置表单、连接测试、详情刷新和批量刷新。
- 浏览器验证桌面与移动端设置页、刷新状态和无配置引导。
